# 学习路径更新说明

## 概述

根据 `题型.md` 中的8个层级，我们重新设计了学习路径，使其更加循序渐进，符合儿童数学学习的认知规律。

## 新的学习路径结构

### 第一章：基础数感训练 (Level 0-1)
- **Level 0: 基础数感 (1-9)**
  - 目标：1-9的加减能瞬间反应，不思考
  - 题型：混合运算
  - 范围：1-9
  - 题数：20题
  - 时间限制：60秒
  - 星级要求：
    - 铜星：5秒/题，80%准确率
    - 银星：3秒/题，90%准确率
    - 金星：2秒/题，95%准确率
  - **例题：**
    - 3 + 4 = **7** (直接反应，不数手指)
    - 8 - 2 = **6** (瞬间说出答案)
    - 5 + 3 = **8** (条件反射)
    - 9 - 4 = **5** (无需思考)

- **Level 1: 凑十基础**
  - 目标：掌握凑成10的组合，6-9与任一数
  - 题型：加法
  - 范围：1-18
  - 题数：20题
  - 时间限制：120秒
  - 解锁条件：完成Level 0并获得银星
  - 星级要求：
    - 铜星：8秒/题，80%准确率
    - 银星：6秒/题，90%准确率
    - 金星：4秒/题，95%准确率
  - **例题：**
    - 7 + 8 → 7 + 3 + 5 = 10 + 5 = **15** (口述"7差3到10")
    - 6 + 5 → 6 + 4 + 1 = 10 + 1 = **11** (口述"6差4到10")
    - 9 + 4 → 9 + 1 + 3 = 10 + 3 = **13** (口述"9差1到10")
    - 8 + 7 → 8 + 2 + 5 = 10 + 5 = **15** (口述"8差2到10")

### 第二章：一位数运算 (Level 2-3)
- **Level 2: 一位数运算(无进位)**
  - 目标：一位数加两位数，不触发进位
  - 题型：混合运算
  - 范围：1-99
  - 题数：20题
  - 时间限制：180秒
  - 解锁条件：完成Level 1并获得银星
  - 星级要求：
    - 铜星：12秒/题，80%准确率
    - 银星：9秒/题，90%准确率
    - 金星：6秒/题，95%准确率
  - **例题：**
    - 24 + 5 = **29** (口答并说"24加5个单位是29")
    - 63 - 7 = **56** (口述"63减7=56")
    - 35 + 4 = **39** (个位5+4=9，十位不变)
    - 82 - 3 = **79** (个位2-3不够，借位后得79)

- **Level 3: 一位数运算(有进位)**
  - 目标：熟练用凑整思维处理进位
  - 题型：混合运算
  - 范围：1-99
  - 题数：20题
  - 时间限制：180秒
  - 解锁条件：完成Level 2并获得银星
  - 星级要求：
    - 铜星：12秒/题，80%准确率
    - 银星：9秒/题，90%准确率
    - 金星：6秒/题，95%准确率
  - **例题：**
    - 29 + 7 → 29+1=30，+6=**36** (口述"补1到30，剩6")
    - 47 + 8 → 47+3=50，+5=**55** (口述"补3到50，剩5")
    - 56 - 9 → 56-6=50，-3=**47** (口述"先减6到50，再减3")
    - 38 + 6 → 38+2=40，+4=**44** (口述"补2到40，剩4")

### 第三章：两位数基础运算 (Level 4-5)
- **Level 4: 两位数运算(无跨十)**
  - 目标：两位数相加相减，个位不跨十
  - 题型：混合运算
  - 范围：1-99
  - 题数：20题
  - 时间限制：240秒
  - 解锁条件：完成Level 3并获得银星
  - 星级要求：
    - 铜星：16秒/题，80%准确率
    - 银星：12秒/题，90%准确率
    - 金星：8秒/题，95%准确率
  - **例题：**
    - 34 + 25 = (个位4+5=9，十位30+20=50) → **59**
    - 82 - 31 = (82减30=52，再减1=) **51**
    - 56 + 23 = (个位6+3=9，十位50+20=70) → **79**
    - 78 - 45 = (78减40=38，再减5=) **33**

- **Level 5: 两位数运算(单处进位)**
  - 目标：处理一种进位或借位，用凑整或分拆法
  - 题型：混合运算
  - 范围：1-99
  - 题数：20题
  - 时间限制：240秒
  - 解锁条件：完成Level 4并获得银星
  - 星级要求：
    - 铜星：16秒/题，80%准确率
    - 银星：12秒/题，90%准确率
    - 金星：8秒/题，95%准确率
  - **例题：**
    - 56 + 37 → 把37当作40-3：56+40=96，96-3=**93** (口述"37=40-3")
    - 50 - 27 → 想27要加多少到50？27+3=30，再+20=50，所以差23 → **23**
    - 48 + 26 → 48+2=50，+24=**74** (口述"先凑整到50")
    - 73 - 28 → 73-30=43，+2=**45** (口述"多减了2，要加回来")

### 第四章：高级运算技巧 (Level 6-7)
- **Level 6: 两位数运算(多处进位)**
  - 目标：涉及两个位置都需处理的进位或退位
  - 题型：混合运算
  - 范围：1-199
  - 题数：20题
  - 时间限制：300秒
  - 解锁条件：完成Level 5并获得银星
  - 星级要求：
    - 铜星：20秒/题，80%准确率
    - 银星：15秒/题，90%准确率
    - 金星：10秒/题，95%准确率
  - **例题：**
    - 78 + 47 → 个位8+7=15，写5进1 → 十位7+4+1=12 → **125** (口述"8+7=15，进1")
    - 93 - 57 → 把57拆成60-3：93-60=33，33+3=**36** (用补数思路)
    - 89 + 56 → 89+1=90，+55=**145** (先凑整，再计算)
    - 156 - 78 → 156-80=76，+2=**78** (多减了2，要加回来)

- **Level 7: 三数运算/混合步骤**
  - 目标：心算三项相加或加减混合，提高耐干扰能力
  - 题型：混合运算
  - 范围：1-199
  - 题数：15题
  - 时间限制：360秒
  - 解锁条件：完成Level 6并获得银星
  - 星级要求：
    - 铜星：30秒/题，80%准确率
    - 银星：24秒/题，90%准确率
    - 金星：18秒/题，95%准确率
  - **例题：**
    - 45 + 28 + 17 → 45+28=73，73+17=**90** (或28+17=45，45+45=90)
    - 120 - 37 + 9 → 120-37=83，83+9=**92**
    - 67 + 34 - 25 → 67+34=101，101-25=**76**
    - 89 - 45 + 67 → 89-45=44，44+67=**111**

## 学习路径特点

1. **循序渐进**：从最基础的数感开始，逐步提升到复杂运算
2. **科学分级**：每个层级都有明确的学习目标和评估标准
3. **灵活解锁**：通过银星解锁机制，确保学生真正掌握当前层级
4. **视觉反馈**：清晰的关卡状态和星级显示，激励学习
5. **个性化**：支持个人进步跟踪和最佳成绩记录

## 使用说明

1. 学生从第一关开始，完成基础数感训练
2. 每关需要达到银星标准才能解锁下一关
3. 系统会自动记录最佳成绩和完成情况
4. 家长可以设置自定义奖励激励孩子学习

## 例题总结

### 学习路径的思维发展过程

**Level 0 → Level 1：从机械记忆到策略思维**
- Level 0: 3+4=7 (机械记忆，条件反射)
- Level 1: 7+8=15 (策略思维，凑十法)

**Level 2 → Level 3：从简单应用到复杂处理**
- Level 2: 24+5=29 (直接相加，无进位)
- Level 3: 29+7=36 (凑整思维，有进位)

**Level 4 → Level 5：从按位计算到灵活策略**
- Level 4: 34+25=59 (按位相加，个位+个位，十位+十位)
- Level 5: 56+37=93 (灵活策略，把37当作40-3)

**Level 6 → Level 7：从单一运算到复合思维**
- Level 6: 78+47=125 (复杂进位，个位和十位都要处理)
- Level 7: 45+28+17=90 (多步运算，需要记忆中间结果)

### 关键学习策略

1. **凑十法**：6+7 → 6+4+3 = 10+3 = 13
2. **凑整法**：29+7 → 29+1+6 = 30+6 = 36
3. **分拆法**：56+37 → 56+40-3 = 96-3 = 93
4. **补数法**：50-27 → 27+23=50，所以50-27=23
5. **按位法**：34+25 → 个位4+5=9，十位30+20=50，结果59

这个新的学习路径设计更符合儿童数学学习的认知规律，能够帮助孩子循序渐进地掌握数学技能。
