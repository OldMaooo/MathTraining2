## 🎯 模块3: 音效系统修复

### 目标
确保所有音效文件正常播放，包括答题、结算、开始等音效。

### 规则
- 音效文件存储在 public/sfx/ 目录
- 支持多种音效：correct.wav, wrong.wav, start.wav, success.mp3
- 异步播放，不阻塞主线程
- 支持音效开关控制

### 显示/反馈
```typescript
// 音效播放函数
const playSfx = (soundName: string) => {
  try {
    const audio = new Audio(`/sfx/${soundName}`);
    audio.volume = 0.5;
    setTimeout(() => audio.play(), 0);
  } catch (error) {
    console.warn('音效播放失败:', error);
  }
};

// 使用场景
- 答对题目: playSfx('correct.wav')
- 答错题目: playSfx('wrong.wav')  
- 开始游戏: playSfx('start.wav')
- 结算页面: playSfx('success.mp3')
```

## 🎯 模块5: 连胜状态修复

### 目标
修复连胜状态显示逻辑，正确计算和显示连续答题天数。

### 规则
- 基于当前日期计算连胜天数
- 未来日期不能标记为已完成
- 今日连胜用不同透明度区分
- 显示今日答题数和轮数统计

### 显示/反馈
```tsx
// 位置: TopNavigationSimple.tsx
const today = new Date().getDay();
const todayIdx = today === 0 ? 6 : today - 1;

const weekDots = Array.from({ length: 7 }).map((_, idx) => {
  const isToday = idx === todayIdx;
  if (profile.streak === 0) {
    return { isActive: false, isToday };
  }
  if (idx > todayIdx) {
    return { isActive: false, isToday };
  }
  const daysFromToday = todayIdx - idx;
  const isActive = daysFromToday >= 0 && daysFromToday < profile.streak;
  return { isActive, isToday };
});
```

## 🎯 模块6: 计时器修复

### 目标
修复计时器显示逻辑，正确显示总时长而非单题时长。

### 规则
- 总时长 = 单题时长 × 题目数量
- 错题惩罚扣除单题时长
- 移除冗余的"总时长"显示

### 显示/反馈
```typescript
// 位置: PlaySimple.tsx
// 设置总时长 = 单题时长 × 题目数量

// 错题惩罚：扣除单题时长
const singleQuestionTime = parseInt(localStorage.getItem('timeLimit') || '5');
setTimeLeft(prev => Math.max(0, prev - singleQuestionTime));
```

### 👤 账号体系与登录注册流程 详细规范

#### **账号管理服务 (AccountService) 数据结构：**
```typescript
interface Account {
  id: string;           // 唯一标识（时间戳+随机字符串）
  name: string;         // 账号名称（用户自定义）
  createdAt: number;    // 创建时间戳
  lastActiveAt: number; // 最后活跃时间戳
}
```

#### **账号操作流程详细规范：**
- **创建账号流程**：
  1. 用户输入账号名称
  2. 系统自动生成唯一ID（时间戳+随机字符串）
  3. 记录创建时间戳
  4. 设置为当前活跃账号
  5. 保存到localStorage

- **切换账号流程**：
  1. 显示所有账号列表
  2. 当前账号用✓标记
  3. 点击切换，更新最后活跃时间
  4. 数据自动隔离加载
  5. 更新UI显示

- **删除账号流程**：
  1. 检查账号数量（至少保留一个）
  2. 确认删除操作
  3. 删除账号数据
  4. 自动切换到第一个可用账号
  5. 清理相关数据

#### **数据隔离机制详细规范：**
- 每个账号独立的数据存储
- 经验值、等级、连胜等数据分离
- 历史记录按账号存储
- 错题集按账号管理
- 设置配置按账号保存
