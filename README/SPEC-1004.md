## 🎯 模块3: 音效系统修复

### 目标
确保所有音效文件正常播放，包括答题、结算、开始等音效。

### 规则
- 音效文件存储在 public/sfx/ 目录
- 支持多种音效：correct.wav, wrong.wav, start.wav, success.mp3
- 异步播放，不阻塞主线程
- 支持音效开关控制

### 显示/反馈
```typescript
// 音效播放函数
const playSfx = (soundName: string) => {
  try {
    const audio = new Audio(`/sfx/${soundName}`);
    audio.volume = 0.5;
    setTimeout(() => audio.play(), 0);
  } catch (error) {
    console.warn('音效播放失败:', error);
  }
};

// 使用场景
- 答对题目: playSfx('correct.wav')
- 答错题目: playSfx('wrong.wav')  
- 开始游戏: playSfx('start.wav')
- 结算页面: playSfx('success.mp3')
```

## 🎯 模块5: 连胜状态修复

### 目标
修复连胜状态显示逻辑，正确计算和显示连续答题天数。

### 规则
- 基于当前日期计算连胜天数
- 未来日期不能标记为已完成
- 今日连胜用不同透明度区分
- 显示今日答题数和轮数统计

### 显示/反馈
```tsx
// 位置: TopNavigationSimple.tsx
const today = new Date().getDay();
const todayIdx = today === 0 ? 6 : today - 1;

const weekDots = Array.from({ length: 7 }).map((_, idx) => {
  const isToday = idx === todayIdx;
  if (profile.streak === 0) {
    return { isActive: false, isToday };
  }
  if (idx > todayIdx) {
    return { isActive: false, isToday };
  }
  const daysFromToday = todayIdx - idx;
  const isActive = daysFromToday >= 0 && daysFromToday < profile.streak;
  return { isActive, isToday };
});
```

## 🎯 模块6: 计时器修复

### 目标
修复计时器显示逻辑，正确显示总时长而非单题时长。

### 规则
- 总时长 = 单题时长 × 题目数量
- 错题惩罚扣除单题时长
- 移除冗余的"总时长"显示

### 显示/反馈
```typescript
// 位置: PlaySimple.tsx
// 设置总时长 = 单题时长 × 题目数量
setTimeLeft(timeLimit * newQuestions.length);

// 错题惩罚：扣除单题时长
const singleQuestionTime = parseInt(localStorage.getItem('timeLimit') || '5');
setTimeLeft(prev => Math.max(0, prev - singleQuestionTime));
```

- 添加防抖机制防止重复提交
- 强制重置机制防止状态卡住
- 键盘和鼠标事件冲突处理

### 显示/反馈
```typescript
// 位置: PlaySimple.tsx
const isSubmittingRef = useRef(false);
const lastSubmitTimeRef = useRef(0);

const handleSubmit = (e: React.FormEvent) => {
  e.preventDefault();
  e.stopPropagation();
  
  const now = Date.now();
  if (now - lastSubmitTimeRef.current < 500) return;
  
  if (isSubmittingRef.current) return;
  
  isSubmittingRef.current = true;
  lastSubmitTimeRef.current = now;

};
```

## 🎯 模块9: 历史记录保存

### 目标
确保每轮游戏完成后正确保存到历史记录。

### 规则
- 游戏结束后立即保存
- 包含完整的答题数据
- 支持历史记录查看
- 数据持久化存储

### 显示/反馈
```typescript
// 位置: PlaySimple.tsx 游戏结束处理
const saveGameHistory = (gameData: GameData) => {
  const history = JSON.parse(localStorage.getItem('mp-history') || '[]');
  history.push({
    ...gameData,
    timestamp: new Date().toISOString(),
    id: Date.now()
  });
  localStorage.setItem('mp-history', JSON.stringify(history));
};
```
